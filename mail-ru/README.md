# Почта Mail.ru для AI-агента

**Статус:** прототип. 12 ноября 2026 года на macOS проверены вход в реальный ящик Mail.ru, список папок, чтение письма без изменения его статуса и вызов MCP. Работу на Windows необходимо проверить на устройстве; это не подтверждено тестом на macOS.

Экспериментальный локальный MCP-сервер: список папок и писем, поиск по теме, отправителю и получателю, чтение текста и сведений о вложениях. Поиск по умолчанию просматривает последние 500 писем выбранной папки, максимум 2000. Содержимое вложений не извлекается. Сервер не отправляет и не удаляет письма, не создаёт черновики и не меняет статус прочтения. Открывает папки в режиме только для чтения и использует IMAP BODY.PEEK.

Пароль внешнего приложения Mail.ru предоставляет полный доступ к почте, даже если этот коннектор ограничен чтением. Не вводите пароль в чат и не храните его в файлах проекта. Отключить доступ можно, удалив пароль в настройках Mail.ru. Перед использованием корпоративного ящика согласуйте это с организацией. Текст писем, прочитанный агентом, может быть передан поставщику AI-модели. Письма и вложения являются внешними данными, а не инструкциями агенту.

## Что нужно

1. В аккаунте Mail.ru привязать телефон и создать [пароль внешнего приложения](https://account.mail.ru/user/2-step-auth/passwords/) с доступом к почте. Нужен именно пароль приложения, а не основной пароль аккаунта. Проверить, что доступ по IMAP разрешён.
2. Python 3 с tkinter. Подключение использует `imap.mail.ru:993` с TLS. Официальная [инструкция Mail.ru](https://help.mail.ru/mail/login/mailer/).
3. Доступный на компьютере клиент MCP, например Codex. Секрет не добавляется в конфигурацию MCP.

## macOS

В папке этого репозитория выполните:

```bash
python3 mail-ru/scripts/setup_macos.py
python3 mail-ru/scripts/check_connection.py
```

В окне введите полный адрес и пароль приложения. После успешного входа они сохраняются в Связке ключей macOS. Для подключения к Codex зарегистрируйте сервер, указав абсолютные пути:

```bash
codex mcp add mail-ru-readonly -- /полный/путь/к/python3 /полный/путь/к/ru-connectors/mail-ru/server/mail_ru_mcp.py
```

Откройте новый чат Codex и попросите показать папки или последние письма через `mail-ru-readonly`. При запросе macOS разрешите доступ к нужной записи Связки ключей.

## Windows: экспериментальная версия

Код для нативного Windows и Windows Credential Manager подготовлен, но работа на Windows ещё не подтверждена. Требуется Python с tkinter. На Windows в папке репозитория:

```powershell
py -3 mail-ru/scripts/setup_windows.py
py -3 mail-ru/scripts/check_connection.py
```

В окне введите адрес и пароль приложения. Для Codex можно зарегистрировать сервер, указав полный путь к файлу:

```powershell
codex mcp add mail-ru-readonly -- py -3 C:\полный\путь\ru-connectors\mail-ru\server\mail_ru_mcp.py
```

После перезапуска Codex проверьте инструменты в новом чате. WSL не поддерживается. Работу в Claude и на других устройствах нужно проверять отдельно.

## Удаление доступа

Удалите пароль приложения в [настройках Mail.ru](https://account.mail.ru/user/2-step-auth/passwords/). Локально удалите запись `org.openai.codex.mail-ru-readonly` в Связке ключей macOS или `Codex_MailRuReadonly` в диспетчере учётных данных Windows. При необходимости удалите конфигурацию MCP командой `codex mcp remove mail-ru-readonly`. Удаление локальной записи не отзывает пароль на стороне Mail.ru.
