# Яндекс Диск для Codex

Пробный MCP-коннектор для macOS. Нужны аккаунт Яндекса, Python 3.9+ и OAuth-токен с правом «Чтение всего Диска» (`cloud_api:disk.read`). Коннектор читает файлы и папки пользовательского Диска. Для корпоративного раздела «Общие диски» в Яндекс 360 предусмотрен отдельный API.

## 1. Получите токен

1. Откройте [Яндекс OAuth](https://oauth.yandex.ru/client/new) под аккаунтом, Диск которого хотите подключить. Создайте приложение типа **Для доступа к API**.
2. Выберите платформу **Веб-сервисы**. В поле **Redirect URI** укажите `https://oauth.yandex.ru/verification_code`.
3. В разделе **Доступ к данным** добавьте **Чтение всего Диска** (`cloud_api:disk.read`) и создайте приложение.
4. Скопируйте **Client ID** из карточки приложения. Вставьте его вместо `CLIENT_ID` в ссылку ниже, откройте её в браузере и разрешите доступ.

   ```text
   https://oauth.yandex.ru/authorize?response_type=token&client_id=CLIENT_ID
   ```

5. Скопируйте значение токена со страницы Яндекса. Вставьте его в скрытое поле Терминала на следующем шаге.

[Права API Яндекс Диска](https://yandex.ru/dev/disk-api/doc/ru/concepts/quickstart) · [Инструкция Яндекса по получению токена](https://yandex.ru/dev/id/doc/ru/tokens/debug-token)

## 2. Подключите Диск

Выполните команду в Терминале из корня тестовой копии репозитория.

```sh
python3 yandex-disk/setup.py connect
```

Терминал принимает токен без отображения символов. Скрипт проверяет доступ к корневой папке и сохраняет токен в отдельной записи Связки ключей. Когда срок действия токена закончится, получите новый и повторите команду.

## 3. Проверьте в Codex

В подготовленной локальной копии есть конфигурация MCP для этого проекта. Откройте корень копии как проект в Codex Desktop, подтвердите доверие проекту, если Codex спросит, и начните новый чат. [Настройки проекта Codex](https://developers.openai.com/codex/config-basic)

Для другой копии репозитория можно открыть временную сессию этой командой из её корня.

```sh
codex -c 'mcp_servers.yandex-disk.command="python3"' \
  -c "mcp_servers.yandex-disk.args=[\"$PWD/yandex-disk/yandex_disk_mcp.py\"]" \
  -c 'mcp_servers.yandex-disk.tool_timeout_sec=120'
```

Для проверки положите на Диск небольшой учебный файл `Проверка Диска.txt` с известным текстом. В новом чате попробуйте три запроса.

1. «Проверь подключение к Яндекс Диску и покажи содержимое корневой папки».
2. «Найди на Яндекс Диске файл “Проверка Диска.txt” и прочитай его».
3. «Скачай этот файл с Яндекс Диска и покажи путь к локальной копии».

Поиск идёт по имени файла, без учёта регистра. За вызов проверяется до 300 имён. Если в ответе есть `next_offset`, агент может продолжить поиск. Поиск в большой коллекции может потребовать несколько вызовов.

Коннектор возвращает до 12 000 символов из текстового файла размером до 1 МиБ. Кодировки UTF-8 и Windows-1251. Документы, таблицы, PDF и другие форматы до 50 МиБ можно скачать во временную папку macOS и открыть локально. Скачанные копии остаются во временной папке. Содержимое, которое агент читает для ответа, может попасть в контекст модели.

## Диагностика

Запустите команды из корня репозитория.

```sh
python3 yandex-disk/setup.py check
python3 -m unittest discover -s yandex-disk/tests -v
```

Для отключения удалите токен из Связки ключей командой `python3 yandex-disk/setup.py disconnect`. Чтобы также отозвать токен у Яндекса, удалите доступ приложения в [Яндекс ID](https://id.yandex.ru/security).
