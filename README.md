# ru-connectors

Локальные коннекторы для подключения российских сервисов к AI-агентам.

- [Почта Mail.ru](mail-ru/README.md): экспериментальный MCP-коннектор для чтения почты по IMAP.

Перед использованием корпоративного ящика проверьте правила организации о передаче данных AI-сервисам. Полученные агентом письма могут передаваться поставщику используемой AI-модели.
