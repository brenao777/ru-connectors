# Яндекс Почта для Codex и Claude Code

Плагин читает и ищет письма, показывает вложения, сохраняет черновики и отправляет текстовые письма через SMTP Яндекса. Это пилотная версия для нативной Windows и macOS. На Windows используйте обычную установку клиента, чтобы плагин мог открыть окно настройки и обратиться к Windows Credential Manager.

## Установка в Codex

Добавьте каталог и установите вариант для своей системы. Команды можно выполнять отдельно.

```sh
codex plugin marketplace add brenao777/yandex-mail-safe --ref main
codex plugin add yandex-mail-windows@yandex-mail-safe
```

На macOS используйте `yandex-mail-macos@yandex-mail-safe`. Если на Windows запуск `codex.exe` запрещён, можно открыть локальную копию этого репозитория как проект в Codex Desktop и выбрать **Plugins → Яндекс Почта → Установить**. После добавления источника может потребоваться перезапуск приложения.

## Установка в Claude Code

В сессии Claude Code выполните по очереди:

```text
/plugin marketplace add https://github.com/brenao777/yandex-mail-safe.git
/plugin install yandex-mail-windows@yandex-mail-safe
```

На macOS используйте `yandex-mail-macos@yandex-mail-safe`. После установки откройте новую сессию.

## Подключение ящика

1. Попросите агента **«Подключи Яндекс Почту»**. На Windows настройка ищет Python 3.9+ с рабочим Tk и проверяет системное хранилище. При необходимости ставит Python 3.14 для текущего пользователя через WinGet, а при отсутствии WinGet использует подписанный установщик с python.org. На macOS настройка ищет подходящий Python и при необходимости ставит его через Homebrew, если он доступен.
2. Включите IMAP и создайте [пароль приложения типа «Почта»](https://yandex.ru/support/yandex-360/business/mail/ru/mail-clients/others). Введите адрес и пароль в локальном окне. Windows хранит пароль в Credential Manager, macOS в Связке ключей. Оба клиента на одном компьютере используют одну системную запись своего варианта плагина.
3. Дождитесь успешной проверки входа по IMAP и SMTP. Она не отправляет письма. Откройте новую сессию после настройки, чтобы клиент заново запустил почтовый сервер.
4. Попросите **«Покажи последнее непрочитанное письмо»**. Затем для проверки отправки попросите **«Отправь на мой тестовый адрес name@example.com письмо с темой “Проверка плагина” и текстом “Тест отправки”»**, указав свой адрес. Проверьте, что письмо пришло. Ответ SMTP сообщает о приёме письма сервером, а получение проверяется в ящике адресата.

Если IMAP или SMTP заблокированы в корпоративной сети либо недоступны для вашего ящика, потребуется доступ со стороны администратора. Если на macOS нет ни Python, ни Homebrew, установите [Python](https://www.python.org/downloads/macos/) и повторите подключение.

## Что доступно

- Поиск по заголовкам, чтение писем без изменения статуса «непрочитано» и чтение выбранных вложений. Для извлечения текста из PDF, DOCX и XLSX при первом обращении могут понадобиться пакеты с PyPI. Сканам PDF нужно распознавание.
- Сохранение текстового черновика и отправка текстового письма по явной просьбе. Для повторного запроса сервер проверяет ключ операции, чтобы избежать дублей. Отправка вложений и HTML в этой версии отсутствует.
- Отвязка ящика удаляет локальную запись с паролем. Отозвать сам пароль приложения можно в Яндекс ID.

## Проверка и изменения

Офлайн-проверки на Windows и macOS покрывают протокол MCP, защиту от повторной отправки и обработку вложений. Для проверки доступа к Яндексу нужен тестовый ящик. Для проверки автоматической установки нужен компьютер без подходящего Python.

Общий сервер и обработчики находятся в Windows-пакете. После их изменения выполните `python3 tools/sync_shared.py`, чтобы обновить копии в macOS-пакете. Оба пакета самостоятельны, поскольку клиенты копируют выбранный плагин в свой каталог.
