# Яндекс Диск для Codex и Claude Code

Пробный MCP-коннектор для macOS и Windows. Нужны Python 3.9+, аккаунт Яндекса и OAuth-токен для чтения и записи. Коннектор работает с пользовательским Диском. Для раздела «Общие диски» в Яндекс 360 предусмотрен отдельный API.

| Что можно сделать | Условия |
| --- | --- |
| Открыть папку, посмотреть свойства файла, найти файл | Поиск по части имени без учёта регистра. За запрос проверяется до 300 имён. Если в ответе есть `next_offset`, агент может продолжить поиск |
| Прочитать текст или скачать файл | Текст до 1 МиБ в UTF-8 или Windows-1251, в ответе до 12 000 символов. Файлы до 50 МиБ скачиваются во временную папку компьютера |
| Создать папку | Родительская папка должна существовать |
| Загрузить файл или записать текст | До 50 МиБ для локального файла и до 1 МиБ для текста в UTF-8. Для замены существующего файла попросите об этом явно и укажите его путь |

## 1. Получите токен

1. Откройте [Яндекс OAuth](https://oauth.yandex.ru/client/new) под аккаунтом, Диск которого хотите подключить. Создайте приложение типа **Для доступа к API** или откройте ранее созданное приложение.
2. Выберите платформу **Веб-сервисы**. В поле **Redirect URI** укажите `https://oauth.yandex.ru/verification_code`.
3. В разделе **Доступ к данным** добавьте **Чтение всего Диска** (`cloud_api:disk.read`) и **Запись в любом месте на Диске** (`cloud_api:disk.write`). Сохраните настройки.
4. Скопируйте **Client ID** из карточки приложения. Вставьте его вместо `CLIENT_ID` в ссылку ниже, откройте её в браузере и разрешите доступ.

   ```text
   https://oauth.yandex.ru/authorize?response_type=token&client_id=CLIENT_ID
   ```

5. Скопируйте значение токена со страницы Яндекса. Если вы подключали пробную версию для чтения, получите новый токен после добавления права записи.

[Права API Яндекс Диска](https://yandex.ru/dev/disk-api/doc/ru/concepts/quickstart) · [Инструкция Яндекса по получению токена](https://yandex.ru/dev/id/doc/ru/tokens/debug-token)

## 2. Подключите Диск

Откройте Терминал на macOS или PowerShell на Windows в папке, которая содержит `yandex-disk`. Выполните команды для своей системы.

macOS

```sh
python3 yandex-disk/setup.py configure
python3 yandex-disk/setup.py connect
```

Windows

```powershell
py -3 .\yandex-disk\setup.py configure
py -3 .\yandex-disk\setup.py connect
```

Если Python на Windows установлен без команды `py`, используйте `python` вместо `py -3`.

`configure` создаёт в папке проекта `.codex/config.toml` и `.mcp.json`. Настройки содержат локальный путь к Python и серверу. Запускайте команду на каждом компьютере после распаковки пробной версии. Если в папке уже есть настройки MCP, используйте для теста отдельную копию проекта.

`connect` принимает токен в скрытом поле. Скрипт проверяет чтение корня и запрашивает у Яндекса адрес для загрузки без создания файла. После успешной проверки токен сохраняется в Связке ключей macOS или Диспетчере учётных данных Windows.

## 3. Проверьте чтение и запись

- **Codex.** Откройте папку, в которой запускали настройку, как локальный проект. Подтвердите доверие проекту, если Codex спросит, и начните новый чат. [Настройки проекта Codex](https://developers.openai.com/codex/config-basic)
- **Claude Code.** Запустите `claude` из той же папки или откройте её в Claude Code. Разрешите MCP-сервер `yandex-disk`, если Claude запросит доступ. [Проектные MCP-серверы в Claude Code](https://code.claude.com/docs/en/mcp)

В новом чате попросите выполнить следующий сценарий.

> Покажи корень Яндекс Диска. Создай папку «Проверка ru-connectors» с сегодняшней датой в имени. Запиши в неё файл «Проверка.txt» с текстом «Запись работает», затем прочитай его обратно.

По умолчанию загрузка сохраняет уже существующие файлы. Если Яндекс принял файл в обработку, агент может проверить операцию по `operation_id`. Если результат загрузки неизвестен, сначала проверьте операцию или целевой путь. [Создание папки](https://yandex.ru/dev/disk-api/doc/ru/reference/create-folder) · [Загрузка файла](https://yandex.ru/dev/disk-api/doc/ru/reference/upload)

## Диагностика

Для проверки токена запустите ту же команду, что при подключении, с действием `check` вместо `connect`. Когда срок действия токена закончится, получите новый и повторите подключение. Действие `disconnect` удаляет токен из системного хранилища. Отозвать доступ приложения можно в [Яндекс ID](https://id.yandex.ru/security).

Автоматические тесты из папки проекта на macOS:

```sh
python3 -m unittest discover -s yandex-disk/tests -v
```

На Windows:

```powershell
py -3 -m unittest discover -s yandex-disk/tests -v
```
