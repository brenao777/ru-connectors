# ru-connectors

Один плагин для Codex и Claude Code на Windows и macOS. В него входят три коннектора:

| Сервис | Возможности |
| --- | --- |
| Яндекс Почта | Чтение и поиск, вложения, текстовые черновики и отправка текстовых писем через SMTP |
| Почта Mail | Чтение и поиск, сведения о вложениях, отправка текстовых писем через SMTP |
| Яндекс Диск | Обзор и поиск файлов, чтение текста, скачивание файлов, создание папок, загрузка файлов и текста |

Почтовые коннекторы читают письма без изменения статуса «непрочитано». Поиск Почты Mail по умолчанию просматривает последние 500 писем выбранной папки, максимум 2000. Коннектор Диска работает с личным Диском подключённого аккаунта: он открывает папки, читает текст до 1 МиБ, скачивает файлы до 50 МиБ и по просьбе пользователя создаёт папки и загружает файлы. Существующие файлы по умолчанию сохраняются.

## Установка в Claude Code

Выполните в сессии Claude Code две команды:

```text
/plugin marketplace add https://github.com/brenao777/ru-connectors.git
/plugin install ru-connectors@ru-connectors
```

## Установка в Codex

```sh
codex plugin marketplace add brenao777/ru-connectors --ref main
codex plugin add ru-connectors@ru-connectors
```

Для Codex Desktop также можно открыть локальную копию репозитория как проект и выбрать **Plugins → ru-connectors → Установить**. При необходимости перезапустите приложение, чтобы появился новый источник.

Все коннекторы используют Git для запуска из плагина. На Windows нужен [Git for Windows](https://git-scm.com/install/windows) с доступной командой `git`, а агент должен работать в нативной Windows.

## Обновление

Если плагин уже установлен, обновите каталог и плагин, затем откройте новую сессию.

В Claude Code:

```text
/plugin marketplace update ru-connectors
/plugin update ru-connectors@ru-connectors
```

В Codex:

```sh
codex plugin marketplace upgrade ru-connectors
codex plugin add ru-connectors@ru-connectors
```

## Подключение почты

1. Включите IMAP и создайте пароль приложения для нужного ящика. См. [Яндекс Почта](https://yandex.ru/support/yandex-360/business/mail/ru/mail-clients/others) и [Почта Mail](https://help.mail.ru/mail/login/mailer/).
2. Откройте новую сессию и напишите **«Подключи Яндекс Почту»** или **«Подключи Почту Mail»**. Можно подключить оба ящика по очереди.
3. Введите адрес и пароль приложения в локальном окне. Windows хранит пароль в Credential Manager, macOS в Связке ключей. Для обоих сервисов проверяются IMAP и SMTP. Проверка ничего не отправляет.
4. Откройте новую сессию и попросите показать последнее письмо, указав нужную почту. Для проверки отправки явно попросите отправить тестовое письмо на свой адрес и укажите, из какого ящика его отправить, тему и текст.

## Подключение Яндекс Диска

1. Создайте приложение на [Яндекс OAuth](https://oauth.yandex.ru/client/new): тип **Для доступа к API**, платформа **Веб-сервисы**, Redirect URI `https://oauth.yandex.ru/verification_code`. В разделе **Доступ к данным** добавьте **Чтение всего Диска** и **Запись в любом месте на Диске**.
2. Скопируйте **Client ID**, подставьте его в ссылку `https://oauth.yandex.ru/authorize?response_type=token&client_id=CLIENT_ID`, откройте её в браузере, разрешите доступ и скопируйте токен со страницы Яндекса.
3. Откройте новую сессию и напишите **«Подключи Яндекс Диск»**. Токен вводится в локальном окне: Windows хранит его в Credential Manager, macOS в Связке ключей. Проверка читает корень Диска и запрашивает адрес для загрузки, ничего не создавая.
4. Откройте новую сессию и попросите показать корень Диска. Для проверки записи попросите создать папку и записать в неё текстовый файл.

Если нужен только просмотр, оставьте приложению право на чтение. Тогда проверка покажет `write: false`, обзор и чтение будут работать, а создание папок и загрузка вернут ошибку. Отозвать доступ приложения можно в [Яндекс ID](https://id.yandex.ru/security), а удалить токен с компьютера — запросом «Отключи Яндекс Диск».

## Python

На Windows настройка проверяет Python 3.9+ с Tk и ставит Python для текущего пользователя, если подходящей версии нет. На macOS она ищет Python и при необходимости устанавливает его через Homebrew, если он есть. Если подходящего Python и Homebrew нет, установите [Python для macOS](https://www.python.org/downloads/macos/) и повторите подключение.

## Старые регистрации

Если установлен старый плагин `yandex-mail-windows@yandex-mail-safe` или `yandex-mail-macos@yandex-mail-safe`, отключите его перед установкой `ru-connectors`, чтобы в новой сессии не дублировались инструменты. Новый плагин использует существующие записи с паролями. То же касается отдельной регистрации MCP `mail-ru-readonly`: её можно отключить, чтобы оставался один экземпляр сервера.

Если Диск подключался пробной версией через `.mcp.json` или `.codex/config.toml` в папке проекта, удалите из них сервер `yandex-disk`. Иначе в сессии будет два набора инструментов Диска. Сохранённый токен остаётся в системном хранилище, и повторно вводить его не нужно.

## Данные

Для корпоративной почты и корпоративного Диска учитывайте правила вашей организации. Содержимое писем и файлов, которое читает агент, может обрабатываться поставщиком модели. Имена, метаданные и содержимое считаются данными: агент не выполняет инструкции из писем и файлов.
